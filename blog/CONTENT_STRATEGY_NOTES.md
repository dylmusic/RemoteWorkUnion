## 1. Biggest gaps (high search interest, currently under/zero coverage)

### A. micro1 has almost no dedicated coverage — yet it's now a core platform
This is the single largest gap. The blog has deep "troubleshooting + legitimacy + interview" clusters for Mercor, Outlier, and Handshake, but micro1 only has two generic explainer articles (`micro1-ai-jobs-expert-ai-training-opportunities`, `micro1-ai-jobs-expert-training-guide`). Meanwhile "is micro1 legit" and micro1's **"Zara" AI interviewer** are actively trending searches in 2026.
- **`is-micro1-legit`** — mirrors the existing `is-mercor-legit` / `is-outlier-ai-legit` / `is-handshake-ai-legit` pattern. High priority.
- **`micro1-zara-ai-interview-questions`** — micro1's AI interviewer ("Zara") is a specific, rising query with no competing RWU page.
- **`micro1-no-response-after-applying`**, **`micro1-interview-failed-reapply`** — replicate the Mercor/Handshake troubleshooting clusters that already perform.
- **`micro1-vs-mercor`** and refreshed three-way comparisons that include micro1 (current comparisons still use the old Mercor/Outlier/Handshake trio).

### B. Competitor-platform name SEO (the "is X legit / X review" pattern at scale)
"Is [platform] legit" and "[platform] review 2026" are among the highest-intent, lowest-competition queries in this niche. The blog already owns Mercor/Outlier/Handshake/Surge/Stellar. Missing, and actively searched:
- **`is-alignerr-legit`**, **`is-mindrift-legit`**, **`is-dataannotation-tech-legit`**, **`turing-ai-jobs`** / **`is-turing-legit`**, **`rws-trainai-jobs`**.
- Each should funnel back to the core three as the recommended starting stack (these competitors = comparison context, not the destination).

### C. Pay-anchored, beginner-intent queries
High-volume head terms the blog touches only indirectly:
- **`data-annotation-jobs-no-experience`** (paired honestly with the $20–$40 entry tier → $50–$200 expert ceiling).
- **`how-much-do-ai-training-jobs-pay`** / **`ai-training-jobs-pay-per-hour`** — a definitive pay-breakdown page anchored on $50–$200/hr.
- **`remote-jobs-that-pay-50-an-hour-no-degree`** — matches a very common search string.

### D. "AI jobs near me" / geo + remote intent
The blog has country pages (US/CA/UK/AU) and `ai-training-jobs-near-me-vs-remote`. Under-covered:
- City/region-agnostic **`work-from-home-ai-jobs-no-phone-no-degree`** (stacks three high-intent modifiers).
- Non-English-market angles already started (bilingual) — expand to specific languages with real demand (Spanish, Portuguese, German, Arabic) only if task demand supports it.

## 2. Topic *types* worth doing more of (proven-intent formats)

1. **"Is [platform] legit?"** — highest-intent, evergreen, low competition. Outlier/Mercor legit pages are search magnets; replicate for every platform name a job-seeker might type (esp. micro1 + competitors above).
2. **Status/troubleshooting longtail** — "under review", "no response after applying", "rejected / reapply", "assessment failed", "no tasks / no projects available", "how long does X take". These already exist for Mercor/Outlier/Handshake and clearly convert; micro1 is missing the whole set.
3. **"How much can you make on [platform] per month"** + realistic-pay explainers — strong intent, supports the $50–$200/hr message when framed honestly.
4. **"[Platform A] vs [Platform B]"** — comparison pages capture decision-stage traffic. Refresh all comparisons to include micro1 in the core trio.
5. **Occupation → AI work bridges** — "best AI jobs for [profession]". The blog covers many; gaps remain for high-headcount fields: **social media managers, customer success / support leads, project managers, HR / recruiters, real estate, marketing/SEO specialists, sales/account executives**. These match the "every field qualifies" positioning and are under-served vs. the law/medicine/finance trio.

## 3. Seasonal / trending angles

- **January "new year, new remote job" wave (Dec–Feb):** publish/refresh beginner + "how to start" + resume content ahead of the Q1 job-search spike.
- **New-grad season (Apr–Jun):** Handshake AI skews student/early-career — push `best-remote-jobs-college-students` + Handshake fellowship content in spring.
- **Layoff news cycles:** "remote income that isn't gig apps / surveys" and "side hustle that uses your expertise" angles spike when tech-layoff headlines run. Keep a couple of evergreen pieces ready to amplify.
- **Model-launch moments:** new ChatGPT/Claude/Gemini releases drive "how AI is trained / get paid to train [model]" curiosity — the `claude/gemini/google ai training jobs` cluster benefits from being current. Add equivalents for any major new model line.
- **"Zara AI interview" / AI-interviewer trend:** AI-conducted screening (micro1's Zara, Mercor's AI interview) is a rising curiosity topic — "how to pass an AI interview" content is both timely and on-brand.
